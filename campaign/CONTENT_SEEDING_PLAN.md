# Content Seeding Plan

This plan defines what may be published after a legitimate public account exists.

## 1. Principle

No account should receive filler content solely to make a backlink.

Seed content must serve one of these purposes:

- introduce the brand;
- answer a real buyer/seller question;
- distribute an existing useful resource;
- create a visual/local discovery asset;
- establish a newsletter/feed;
- explain the platform's ongoing content purpose.

## 2. Publishing-platform families

### Medium

**Execution rule: manual platform actions only.** Medium Rules currently prohibit automated/systematic/programmatic account registration and posting. Codex may prepare drafts, copy and QA, but must not execute automated signup/posting.

Recommended role:
- educational essays;
- buyer myths;
- process explanations;
- selected market explainers.

First-content candidates:
- “Mua nhà ở Mỹ nên bắt đầu từ đâu?”
- “Pre-approval giúp người mua hiểu điều gì?”
- “Inspection và appraisal khác nhau thế nào?”

Use original/adapted copy, not mass duplicate posts.

### Substack

Recommended role:
- newsletter;
- weekly/biweekly market + buyer education;
- Open House digest when there is enough value.

Initial issue:
- brand introduction;
- what subscribers will receive;
- link to canonical website.

### Blogger / WordPress.com

Recommended role:
- supporting educational publication;
- long-lived resource hub.

Do not mirror all nhamycali.com posts.

### Tumblr

Recommended role:
- shorter visual/text snippets;
- selected home/lifestyle/property content.

### Google Sites

Recommended role:
- compact public resource hub when there is a real navigation/use case;
- not a doorway-site network.

### Weebly / Strikingly

Use only if a distinct public purpose is defined. Do not create redundant microsites solely for backlinks.

## 3. Visual platforms

### Pinterest

**Current campaign status: excluded by owner.**

NHÀ MỸ CALI already has a Pinterest presence, but Pinterest is not a current channel-development priority for this program.

Do not:
- create a second account;
- seed boards;
- publish pins;
- modify the existing account for SEO purposes.

Revisit only if the owner explicitly reactivates Pinterest later.

### Behance

Use only for legitimate design/creative assets such as:
- property marketing design;
- brand design;
- campaign case studies.

Do not use as a generic real-estate backlink profile if there is no creative portfolio.

### 500px

Use only if NHÀ MỸ CALI has rights to publish high-quality original real-estate/local photography.

## 4. Social/discussion platforms

### Bluesky

Status: **pilot completed 2026-09-30**.

Role:
- short educational posts;
- market/news commentary;
- new resources;
- brand updates.

Canonical profile:
- https://bsky.app/profile/nhamycali.bsky.social

Do not recreate the account. Future posting should follow normal social-content planning rather than signup/pilot workflow.

### Reddit

No automated seeding links.

Any participation needs:
- subreddit-specific research;
- community-rule compliance;
- genuine contribution;
- appropriate self-promotion disclosure.

### Disqus

No automated comment promotion.

Profile may be created if there is a legitimate commenting workflow.

## 5. Distribution/readers

### Feedly

Removed from active SEO/account signup after live research. Following a source is primarily a private content-consumption workflow, not a meaningful public backlink.

Optional use:
- internal RSS monitoring;
- checking whether the NHÀ MỸ CALI feed is discoverable.

### Inoreader

Removed from active SEO/account signup. Current Terms explicitly identify automated registrations for SEO boosting as abusive.

Optional use:
- manually configured internal monitoring only.

### Other readers/distribution platforms

NewsBlur, Feeder, Follow.it, Feedspot and The Old Reader still require individual live research before any execution.

Do not create fake “content” inside a feed reader just for a link.

## 6. Link-in-bio/entity pages

Examples:

- Linktree
- Lnk.bio
- Gravatar

About.me is currently excluded from NHÀ MỸ CALI brand signup under the live Terms interpretation. It may only be reconsidered as a Helen personal profile with explicit approval.

Purpose:
- entity consistency;
- a concise public identity;
- navigation.

Avoid building many identical link pages solely for ranking.

## 7. Content source priority

When seeding content, prefer:

1. verified original NHÀ MỸ CALI website content;
2. current property/Open House information;
3. evergreen educational topics;
4. original local commentary;
5. lifestyle “Nhà Vui” material.

Never seed from unverified scraped third-party copy.

## 9. Success criteria

A seeded account is successful when:

- profile is complete and consistent;
- first content is useful;
- canonical website is linked naturally;
- no spam pattern is created;
- the platform has a plausible ongoing role.
