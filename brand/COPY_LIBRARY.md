## 17. Adapting copy per platform

When a platform imposes a character limit:

1. Preserve brand name.
2. Preserve California / San Jose-Bay Area context where space allows.
3. Preserve Vietnamese-audience positioning.
4. Prefer value proposition over credentials when only one line fits.
5. Add Helen/CalRE only where profiles support a fuller About section.
6. Do not cram all fields into a bio.

---

## 18. Copy QA

Before saving any public profile copy, verify:

- Is the name correct?
- Is the website canonical?
- Did we accidentally invent an official relationship?
- Is any dynamic statistic present? If yes, verify it.
- Is the language useful to a real reader?
- Would this copy still make sense if there were no SEO benefit?

If the last answer is “no,” rewrite it.
