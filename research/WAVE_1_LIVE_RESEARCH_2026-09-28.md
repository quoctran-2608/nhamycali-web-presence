# Wave 1 Live Research — 2026-09-28

Purpose: verify the current platform reality **before** Codex attempts account creation or profile changes.

This document records public research performed on 2026-09-28. Platform interfaces, pricing and policies can change; re-check the official source at execution time.

## Executive decision

The original Wave 1 list was intentionally narrowed after live policy/product research.

### Keep active

- **Bluesky** — strong brand/entity candidate; official organizations are allowed and Bluesky explicitly encourages organizations to use their own domain as the handle.
- **Substack** — strong publishing/newsletter candidate; profile and publication can link to the canonical website.
- **Blogger** — viable supporting publication if it has a distinct editorial purpose.

### Existing accounts: audit, do not create

- **Gravatar** — an existing Helen Ha Nguyen profile was found and already links to NHÀ MỸ CALI.
- **Linktree** — official account already exists; public audit completed.

### Manual-only / human-created

- **Medium** — valuable publishing option, but Medium Rules explicitly prohibit registering accounts or posting content automatically/systematically/programmatically.
- **About.me** — current Terms frame the service as a personal page and state that the user will use it for personal use, not on behalf of or for the benefit of a third party. Do not create a brand account automatically. It may be reconsidered only as a Helen personal profile with human approval.

### Remove from SEO/account-creation campaign

- **Feedly** — useful as a feed reader/discovery tool, but following a source is fundamentally a user/private content-consumption workflow, not a public backlink asset.
- **Inoreader** — Terms explicitly list “Automated registrations for SPAM, SCAM, SEO boosting and other similar purposes” as abusive behavior. Do not automate registration for this campaign.

### Deferred until a real resource-hub concept exists

- **Google Sites** — technically supports public sites and outbound buttons/links, but creating a second thin site merely for a backlink would conflict with this project's quality policy. Only use if a distinct public resource hub is approved.

# 4. Medium

## Current product facts

A Medium profile can:
- set a public display name;
- upload a profile image;
- use a bio of up to 160 characters;
- include a link in the bio;
- customize an About page with hyperlinks.

Source:
- https://help.medium.com/hc/en-us/articles/115004747067-Your-profile-page

A Medium publication provides:
- a dedicated publication homepage;
- publication branding;
- editors/writers;
- newsletter features;
- a publication URL.

However, Medium currently requires an **active Medium membership subscription** to create a publication.

Source:
- https://help.medium.com/hc/en-us/articles/115004681607-Getting-started-with-a-Medium-publication

## Critical automation restriction

Medium Rules explicitly prohibit:
- registering accounts automatically/systematically/programmatically;
- posting content automatically/systematically/programmatically;
- artificial interactions;
- automatic devices/scripts accessing the service for prohibited purposes.

Source:
- https://help.medium.com/hc/en-us/articles/213477928-Medium-Rules

## Existing-account search

Targeted public web search did not find a clear NHÀ MỸ CALI Medium profile/publication.

This is not proof of absence. Search again inside Medium before human signup.

## Recommended action

Medium remains strategically useful, but:
- **account creation must be manual**;
- publishing should be performed through normal human-authorized Medium UI;
- Codex may prepare bio, About copy, article drafts, images and QA outside the platform;
- do not have Codex run an unattended Medium signup/posting bot.

Initial recommendation:
- start with a normal profile first;
- create a branded publication only if the owner accepts an active Medium membership and there is an ongoing editorial plan.

## Automation decision

**Manual platform execution; Codex may prepare content and instructions.**

# 8. Feedly

## Current product facts

Feedly documentation describes a **Follow Sources** workflow:
- search for a website or URL;
- follow the source in the user's account;
- use RSS Builder if the source is not already available.

Source:
- https://docs.feedly.com/article/806-how-to-follow-sources

This is primarily a content-consumption/discovery workflow inside a user's Feedly workspace.

Feedly API terms also say applications should not add/remove feeds from a user's account without explicit user consent/action.

Source:
- https://developers.feedly.com/reference/feedly-api-terms-of-service

## SEO decision

Following nhamycali.com in a private Feedly account is **not a meaningful public backlink strategy**.

There may be discovery value if Feedly already recognizes the site's feed, but that does not justify creating an account for SEO.

## Recommended action

Remove from active SEO/account-creation Wave 1.

Optional later use:
- internal content monitoring;
- verifying RSS discoverability.

## Automation decision

**No account creation for backlink/SEO purposes.**

# Research limitation

A “no match” in public web search is **not proof that no account exists**. Some profiles may be unindexed, private, recently created or discoverable only through internal platform search.

Therefore the final account-existence check always happens immediately before signup.
